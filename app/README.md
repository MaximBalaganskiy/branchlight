# Gitaur application

See [the workspace README](../README.md) for setup, features, shortcuts, architecture, and preview limitations.

From this directory: `npm start`, `npm test`, `npm run test:e2e`, or `npm run pack`.

The logo source is `src/assets/gitaur.svg`. Run `npm run icons` after editing it to regenerate the desktop icons and favicon. The approved logo reference is `../docs/images/gitaur-logo.png`.

Gitaur was previously named Branchlight. The application identifier and browser storage keys retain their original names to preserve existing preferences, layouts, recent repositories, and merge drafts. Native configuration accepts `GITAUR_GIT`, `GITAUR_REPO`, `GITAUR_USER_DATA`, and `GITAUR_EDITOR_EXE`; the corresponding `BRANCHLIGHT_` variables remain supported as fallbacks. Historical release audit documents retain the name used for those releases.
